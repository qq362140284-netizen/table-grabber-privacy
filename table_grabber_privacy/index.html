Privacy Policy — Table Grabber

隐私政策 — Table Grabber（网页表格提取扩展）
Effective date / 生效日期: 2026-10-19
100% Local · Zero Data Collection
The short version / 简而言之： Table Grabber runs entirely inside your browser. It does not collect, store, or transmit any personal data, browsing history, or table content. There is no server, no analytics, no advertising, and no third-party SDK. Everything you extract stays on your device.
Table Grabber 完全在你的浏览器本地运行。不收集、不存储、不传输任何个人数据、浏览历史或表格内容。无服务器、无分析、无广告、无第三方 SDK。你提取的一切数据都留在你的设备上。

1. What We Collect / 我们收集什么

Nothing. Table Grabber does not collect any personal information, browsing history, page content, or table data. All table detection, extraction, and export happen locally in your browser's memory.

  • No account or login is required.
  • No cookies are set by the extension.
  • No network requests are made by the extension.
中文：不收集任何数据。Table Grabber 不收集任何个人信息、浏览历史、页面内容或表格数据。所有表格检测、提取、导出均在你的浏览器内存中本地完成。无需账号登录；不设置 Cookie；不发起任何网络请求。

2. Permissions We Request / 我们申请的权限及用途

We request only the minimum permissions needed for the core function, and we do not request sensitive permissions such as <all_urls>, browsing history, or cookies.

Permission / 权限Purpose / 用途
activeTabAccess the current tab only when you click the icon, to detect tables on that page. / 仅在你点击图标时访问当前标签页，用于检测该页表格。
scriptingInject the extraction script into the current page only when you click the icon. / 仅在你点击图标时向当前页面注入提取脚本。
downloadsSave the exported Excel / CSV file to your downloads folder. / 将导出的 Excel / CSV 文件保存到你的下载目录。
clipboardWriteCopy the extracted table to your clipboard. / 将提取的表格复制到剪贴板。
中文：我们仅申请核心功能所需的最小权限，不申请 <all_urls>、浏览历史、Cookies 等敏感权限。上表逐项说明每个权限的用途；所有页面访问都只发生在你主动点击图标的那一刻。

3. How Your Data Is Processed / 数据如何处理

  • Table detection, normalization (rowspan/colspan), and conversion (Excel/CSV/clipboard) all run locally in your browser.
  • Exported files are written directly to your local downloads folder via the browser's download API.
  • At no point is any page content or table data sent to a remote server.
中文：表格检测、合并单元格规整、格式转换（Excel/CSV/剪贴板）全部在浏览器本地完成；导出文件通过浏览器下载 API 直接写入你的本地下载目录；任何页面内容或表格数据在任何环节都不会发送到远程服务器。

4. Third Parties / 第三方

Table Grabber embeds no third-party SDKs, analytics, advertising, or tracking libraries. Because we collect no data, we share no data with any third party.

中文：Table Grabber 不嵌入任何第三方 SDK、分析、广告或跟踪库。由于我们不收集数据，因此也不会与任何第三方共享数据。

5. Data Retention / 数据保留

We retain no data, because we collect none. The extension does not persist browsing data or table content between sessions; extracted results exist only in memory until you export or close the popup.

中文：我们不保留任何数据（因为不收集）。扩展不会在会话之间持久化浏览数据或表格内容；提取结果仅存在于内存中，直到你导出或关闭弹窗。

6. Children's Privacy / 儿童隐私

Table Grabber is a general-purpose productivity tool and is not directed at children under 13. We do not knowingly collect any data from children.

中文：Table Grabber 是通用生产力工具，不面向 13 岁以下儿童，我们不会故意收集儿童的任何数据。

7. Changes to This Policy / 政策变更

If this policy changes, we will update this page and revise the "Effective date" above. Material changes will be reflected in the extension's store listing.

中文：如本政策变更，我们将更新本页面并修订上方"生效日期"；重大变更会在扩展的商店页面中体现。

8. Contact / 联系方式

Questions about this policy: please open an issue on the project repository or contact the publisher via the email listed on the Chrome Web Store listing.

中文：对本政策有疑问：请在项目仓库提交 issue，或通过 Chrome Web Store 商店页面所列的联系邮箱联系发布者。
